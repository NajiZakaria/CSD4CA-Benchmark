# CSD4CA Benchmark

**A reproducible benchmarking tool for smartphone continuous behavioral authentication.**

This repository accompanies the research work *CSD4CA: A Contextual Multimodal Smartphone Dataset and Benchmark for Continuous Authentication*.

CSD4CA provides touchscreen swipe trajectories and associated motion sensor measurements collected across three usage scenarios (Normal, Walking, and Stressful) and two recording sessions.

The benchmark supports classical machine-learning and deep-learning models, with evaluations covering matched-scenario, cross-scenario, and cross-session authentication.
